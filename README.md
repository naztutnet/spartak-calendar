# Календарь матчей ФК «Спартак-Москва»

Этот репозиторий используется для публикации календаря матчей мужской футбольной команды **«Спартак-Москва»** в формате iCalendar (`.ics`).

## Подписка на календарь

После добавления файла календаря его можно подключить на iPhone, Mac, в Google Calendar и других приложениях.

Ссылка для подписки через `webcal`:

```text
webcal://raw.githubusercontent.com/naztutnet/spartak-calendar/main/spartak-moscow.ics
```

Обычная HTTPS-ссылка:

```text
https://raw.githubusercontent.com/naztutnet/spartak-calendar/main/spartak-moscow.ics
```

## Как подключить на iPhone

1. Откройте **Настройки**.
2. Перейдите в **Приложения → Календарь → Учётные записи календаря**.
3. Нажмите **Добавить учётную запись → Другое**.
4. Выберите **Добавить подписной календарь**.
5. Вставьте ссылку `webcal://` и сохраните подписку.

После обновления файла `.ics` изменения будут автоматически появляться у подписчиков календаря.

## Содержимое репозитория

- `README.md` — описание проекта и инструкция по подключению.
- `spartak-moscow.ics` — календарь матчей «Спартака».

## Важно

Расписание матчей может меняться из-за переносов, решений лиги, телевизионных трансляций и участия клуба в турнирах. Перед поездкой на матч рекомендуется проверять дату и время на официальных ресурсах клуба и турнира.
